The question

For millennia, trust has rested on whoever held the record.

Trust is a foundation of civilization and economic life. Records have grown more powerful and more connected, but a receiver still has to ask the same question before acting: is this record’s evidence, timing and authority what it claims to be?

How it works

A signature shows integrity. SMVRS checks what the record says.

A portable signed record carries its evidence commitments, events, time and pinned rule profile. Two separately built verifiers recompute the proof on the receiver’s side and return an explainable result.

01

Portable record

A signed .smvr.json with identity, evidence, events, time and rules.

02

Two verifiers

Python (A) and Node.js (B), built separately from one specification.

03

Agreement gate

A record is VERIFIED only when both verifiers agree.

04

Explainable result

VERIFIED, or FAILED with the exact reason code.

Concept · Value · Impact

One invention, three answers.

01 · CONCEPT

Beyond the signature

A digital signature establishes that a message is authentic and unchanged. SMVRS adds a second layer: it checks the relationships among identity, authority, behavior, evidence, time and policy, without relying on the issuing system’s success message.

02 · VALUE

Independent, repeatable, explainable

Two independently built verifiers recompute the proof. Standard cryptography (SHA-256, Ed25519), no special hardware, designed for integration through APIs. The benefit: catching a mismatched record before money, care or goods move.

03 · IMPACT

Trust that travels with the record

Trust is not declared; it is independently verified. SMVRS is designed so that records can be checked in any place, any scenario, at any time, by people, institutions and machines alike.
